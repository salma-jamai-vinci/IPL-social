## Project description : 

This project was developed as part of the DevOps exam.
It sets up a DevOps environment with a CI pipeline named : main.yml, using GitHub Actions.

The project follows the TDD (Test Driven Development) methodology to validate
a TypeScript password checking function.
Built-in TypeScript functions are not used to validate emails. The goal is to design and implement the validation function independently.
Tests are automatically executed when a Pull Request is created targeting the
main branch.


## Command to run the tests: 
npm test
